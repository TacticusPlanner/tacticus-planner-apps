## Measured contrast pairs (task 1.3)

Method: OKLCH tokens from `packages/ui/src/styles/globals.css` (`:root` and `.dark`) converted to sRGB (Oklab matrices, gamut-clamped); CSS alpha (`bg-input/50`, `bg-sidebar/50`, `ring-foreground/5|10`, `ring-ring/30`, `bg-primary/80`, `text-primary-foreground/70`, `opacity-50` disabled) composited in gamma-encoded sRGB over the stated backdrop, as browsers do; WCAG 2.x relative luminance and ratio. Class/alpha values were read from `packages/ui/src/components/{input,button,card,dialog,popover,switch,tabs,progress,tooltip,sidebar}.tsx` and `apps/web/src/fsd/app/layout/*`. Script (throwaway, not in repo): scratchpad `mc.mjs`; task 2.5 should port the same OKLCH conversion + alpha compositing into a test. Computed from tokens, not sampled from rendered pixels; the browser-computed lightness in the table above was not re-checked against these hex values.

Classes: **text** = enabled text, min 4.5:1. **ui** = enabled meaningful cue (control boundary/fill, selection, focus, progress), min 3:1. **disabled** = evaluated separately, WCAG exempts it; recorded for recognizability only. **decor** = decorative surface separation, no contrast requirement (value shown only for hierarchy context; do not inflate).
